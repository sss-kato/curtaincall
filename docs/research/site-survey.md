## 0. 結論

**5団体すべてから情報を取得できる見込み。うち2団体は RSS が使える。**

| 団体 | 取得方法 | 難易度 | 備考 |
|---|---|---|---|
| ホリプロステージ | **RSS** | ★ 易 | WordPress 標準フィード。カテゴリ付き |
| 劇団☆新感線 | **RSS** | ★ 易 | 別ドメインのブログに存在。カテゴリ付き |
| 宝塚歌劇団 | HTML 解析 | ★★ 中 | 静的 HTML。URL 規則が明快 |
| 劇団四季 | HTML 解析 | ★★ 中 | 静的 HTML。ページネーションあり |
| 東宝 | HTML 解析 | ★★★ やや難 | サイトが複数ドメインに分散 |

**JavaScript による動的生成は1件もなかった。** 全サイトがサーバーレンダリングの HTML を返すため、ヘッドレスブラウザ（Puppeteer 等）は不要。単純な HTTP 取得と HTML パースで済む。これは実装コストとGitHub Actions の実行時間の両面で大きい。

## 2. 劇団☆新感線

| | |
|---|---|
| **フィード URL** | `https://blog.vi-shinkansen.co.jp/?feed=rss2` |
| **形式** | RSS 2.0（WordPress） |
| **件数** | 10件 |
| **カテゴリ** | **あり**（`NEWS`、作品名など） |

### 注意点：公式サイトとブログでドメインが分かれている

```
www.vi-shinkansen.co.jp       ← 公式サイト。ニュース本文は無い
  └ /feed/                     ← 空（0件）。使えない
  └ /news/feed/                ← 空（0件）。使えない

blog.vi-shinkansen.co.jp      ← ★ 実際のニュースはここ
  └ /?feed=rss2                ← ★ 10件。これを使う
```

公式サイトの「NEWS&TOPICS」は、このブログへのリンク集になっている。**公式ドメインのフィードは空なので、誤って参照しないこと。**

### 取得サンプル

```
title    : ／爆烈忠臣蔵／ゲキ×シネ2027年1月8日(金)全国公開決定！！
link     : https://blog.vi-shinkansen.co.jp/?p=13727
pubDate  : Fri, 11 Sep 2026 03:00:00 +0000
category : NEWS / 爆烈忠臣蔵
```

記事 URL が `?p=13727` というクエリ形式である点に注意（ID の抽出は容易）。

### robots.txt

```
User-agent: *
Disallow: /wp/wp-admin/
Allow: /wp/wp-admin/admin-ajax.php
```

制限なし。

### 評価

**扱いやすい。** ゲキ×シネ（映像化）の情報がカテゴリ付きで流れてくるため、優先カテゴリ「配信・映像化」との相性が良い。

## 3. 宝塚歌劇団

| | |
|---|---|
| **ニュース一覧** | `https://kageki.hankyu.co.jp/news/` |
| **RSS** | **なし** |
| **記事 URL 規則** | `/news/YYYYMMDD_NNN.html`（例：`/news/20260913_002.html`） |
| **一覧の件数** | 100件以上（2016年まで遡って1ページに掲載） |
| **レンダリング** | サーバーサイド（静的 HTML） |
| **カテゴリ** | あり（公演種別・組の分類タグ、「新」バッジ） |

### 取得サンプル

```
2026.09.13  宝塚友の会『ステージトーク in 東京』宙組 無料配信の実施について  /news/20260913_002.html
2026.09.13  ＜公演時間＞月組 兵庫県立芸術文化センター 阪急 中ホール公演      /news/20260913_001.html
2026.08.28  宝塚大劇場レストラン 星組公演特別メニューについて               /news/20260828_001.html
```

### 好条件

- **1ページに全件が載っている**ためページネーション処理が不要
- URL に日付が埋まっているため、**ID の生成と日付の抽出が URL だけで完結**する
- 組（花・月・雪・星・宙）の分類タグが付いており、将来の組別フィルタに使える

### robots.txt

**存在しない（HTTP 404）。** クロールの制限は設けられていない。

### 利用規約（`/rules.html`）

> すべてのデジタル情報は著作者に許可なく、無断で複製・二次利用などすることはできません
> 他のウェブサイトや印刷物に転用することは固くお断りいたします

- **自動取得・クローリングについての記述はない**
- **リンクは許諾不要**（「リンクの内容について責任を負わない」とのみ記載され、事前許可の要求はない）

トップページにも同旨の記載：

> 当ホームページに掲載している情報については、当社の許可なく、これを複製・改変することを固く禁止します。

### 評価

**技術的には最も扱いやすい部類。ただし規約の文言は5団体中で最も厳しい。** 「複製・二次利用」「他のウェブサイトへの転用」を明示的に禁じている。

本アプリは**見出しとリンクのみを扱い、本文を保持しない**設計のため、私的利用の範囲では問題は生じにくい。ただし §6 の法的評価を参照のこと。

|---|---|

| **RSS** | **なし** |
| **記事 URL 規則** | `/navi/news/renewinfo/NNNNNN.html`（例：`/navi/news/renewinfo/037984.html`） |
| **一覧の件数** | 10件／ページ（「前へ」「次へ」のページネーションあり） |
| **レンダリング** | サーバーサイド（静的 HTML） |

### 取得サンプル

```
2026.09.12  『バック・トゥ・ザ・フューチャー』東京公演 明日13日（日）「四季の会」会員先行予約開始！
2026.09.11  『コーラスライン』全国公演 明日12日（土）「四季の会」会員先行予約開始！
2026.09.10  『マンマ・ミーア！』広島公演に向けて――稽古が始まりました！
```

**チケット先行予約の告知が高頻度で流れている。** 優先カテゴリ「チケット情報」との相性が良い。記事 ID（`037984`）は連番であり、更新頻度は概ね1日1件程度と推定される。

### robots.txt

```
User-agent: Googlebot-Image
Disallow: /applause/ghostandlady/images/btn_guide.png
Disallow: /applause/ghostandlady/images/btn_info.png
```

**画像2枚を Google 画像検索から除外しているだけ。** 一般クローラーへの制限は一切ない。

### 利用規約

独立した「利用規約」ページは見つからなかった（`/navi/terms/` は 404）。フッターに以下の記載：

> Copyright SHIKI THEATRE COMPANY. 当サイトの内容の一切の無断転載、使用を禁じます。

プライバシーポリシーは `/site_info/privacy/` に存在。

### 実装上の注意

初回取得時は複数ページを辿る必要があるが、**定常運用では1ページ目だけで足りる**（1日1件程度の更新頻度に対し、1ページに10件あるため）。初回のみ3〜5ページ遡って取得する設計とする。

### 情報源の候補

| パス | 内容 | 件数 |
|---|---|---|
| `/stage/topics/` | **トピックス。実質的なニュース源** | 12件以上（2026年5月〜9月） |
| `/stage/news/` | お知らせ | 4件／ページ（更新頻度は低く、年に数件） |

**`/stage/topics/` を主たる情報源とする。** `/stage/news/` は重要告知（チケットシステムのリニューアル等）が中心で更新頻度が低いが、内容の重要度は高いため補助的に取得する。

### robots.txt — 5団体中で最も寛容

```
User-agent: *
Allow: /

# 具体的なAIボットの許可
# GPTBot (OpenAI), Google-Extended (Geminiなど)
User-agent: GPTBot
Allow: /

User-agent: Google-Extended
Allow: /

Sitemap: https://www.toho.co.jp/sitemap.xml
```

**AI クローラーを名指しで明示的に許可している。** 全体も `Allow: /`。クロールに対する姿勢が最も開かれている。

### 評価

ドメインが分散しているため、**記事の URL 正規化処理**（リンク先が `toho.co.jp` か `tohostage.com` か `toho-navi.com` かを吸収する）が必要。実装コストは他の4団体より高い。

## 6. 法的な評価

### 6.1 現状（自分専用・Phase 1）

**問題は生じにくい。**

- 個人が自分のために情報を集めて閲覧する行為は、著作権法30条の**私的使用のための複製**の範囲内
- 本アプリは**記事本文を保持せず、見出し・URL・日付のみ**を扱う
- 見出しについては、判例上ニュース記事の見出しに著作物性が認められにくいとされている（読売オンライン事件・知財高裁 平成17年）
- リンクを張る行為自体は著作権侵害にあたらない
- robots.txt でクロールを制限しているサイトは**1件もない**

### 6.2 Phase 2（TestFlight で身内共有）に進む場合

**ここで性質が変わる。注意が必要。**

「私的使用」は個人または家庭内に準ずる限られた範囲が対象とされる。**観劇仲間への配布はこの範囲を超える可能性がある。**

宝塚（「他のウェブサイトへの転用を固く禁止」）と四季（「一切の無断転載、使用を禁じます」）は文言が厳しく、リスクは相対的に高い。

**推奨する緩和策：**

| 対策 | 内容 |
|---|---|
| 本文を保持しない | 既に要件に反映済み（§7）。見出し・リンク・日付のみ |
| 出典を明示する | 各記事に団体名を必ず表示し、出典が明確になるようにする |
| 公式サイトへ誘導する | 記事の閲覧は必ず公式サイト上で行わせる（既に F-03 で担保） |
| サムネイルの扱いを見直す | **画像の複製は本文以上にリスクが高い。** 身内共有の段階では、画像をアプリ側にコピーせず公式サイトの URL を直接参照するか、サムネイル表示自体を無効化する |
| アクセス頻度を守る | 1時間おき・サーバー側で1回のみ（既に要件に反映済み） |

### 6.3 Phase 3（App Store 公開）

**本格的な許諾の検討が必要。** 各団体への利用許諾の打診、または情報源を RSS 提供元（＝配信を前提に公開しているもの）に限定するなどの再設計を要する。現時点ではスコープ外のため、判断を先送りする。

## 7. 実装方針への反映

### 7.1 収集処理の構成

```
sources/
  horipro.ts      … RSS パース（rss-parser）
  shinkansen.ts   … RSS パース（rss-parser）
  takarazuka.ts   … HTML パース（cheerio）
  shiki.ts        … HTML パース（cheerio）+ 初回のみページ送り
  toho.ts         … HTML パース（cheerio）+ URL 正規化
```

要件 §9 の R-2 に従い、**1サイトの失敗が他に波及しない**よう、各ソースを独立させ `Promise.allSettled` で並行実行する。

### 7.2 使用ライブラリの見通し

| 用途 | ライブラリ |
|---|---|
| RSS パース | `rss-parser` |
| HTML パース | `cheerio` |
| HTTP 取得 | Node.js 標準 `fetch` |

**ヘッドレスブラウザは不要。** 全サイトが静的 HTML を返すことを確認済み。

### 7.3 カテゴリ判定

- **ホリプロ・新感線**：フィードの `category` をそのまま利用できる
- **宝塚**：一覧ページの分類タグを利用できる
- **四季・東宝**：タイトルのキーワードから判定する（「発売」「先行」「抽選」→ チケット、「配信」「Blu-ray」「ゲキ×シネ」→ 映像化 など）

要件 §11 の未決定事項3（カテゴリ判定のキーワード定義）は、Phase 2 で実データを見ながら詰める。

### 7.4 User-Agent

要件 §5 に従い、以下のように素性を明示する。

```
CurtainCall/1.0 (personal news reader; +https://github.com/<user>/CurtainCall)
```
