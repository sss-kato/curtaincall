## 1. 目的

ホーム（S-01）・保存（S-02）・設定（S-03）の 3 画面で共通して使う部品と表示ルールを 1 か所に定める。本書は単独の画面ではなく、各画面定義書から `S-00/E-nn` の形で参照される。ユーザーはどの画面でも同じ見た目の下部タブバーで画面を移動し、同じ形の記事セルで記事を識別し、同じ形の状態表示（読み込み中・空・オフライン・エラー）で状況を把握できる。

本書が定めるのは次の 4 つ。

1. 下部タブバー（要件 §8）
2. 記事セル（F-02・F-05・F-06・F-11）
3. 共通状態表示（各画面の §5 が参照する）
4. 団体名とカテゴリアイコンの表示対応表（要件 §3.1・§3.3・§7）

本書が定めないもの（各画面の担当）：上部の団体タブと横スワイプ（S-01）、未読フィルタ（S-01）、一覧の並び順と更新記事の先頭再表示（S-01）、Pull to Refresh（S-01）、保存記事の一覧（S-02）、既読の一括クリア（S-03）、ブラウザの選択（S-03）。

## 3. 画面構成

本書は部品集のため、部品ごとにワイヤーフレームを示す。各画面での配置は S-01〜S-03 の §3 が決める。

### 3.1 下部タブバー E-01

```
├──────────────────────────────┤
│ E-01 下部タブバー             │
│  E-02 ホーム  E-03 保存  E-04 設定 │
└──────────────────────────────┘
```

- 画面の最下部に固定。iOS 標準のタブバーの高さ・セーフエリアに従う
- 各タブはアイコン＋ラベルの縦並び。選択中のタブはアイコンとラベルがアクセント色、非選択はセカンダリ色（ST-20）

### 3.2 記事セル E-10

```
┌──────────────────────────────────────────────┐
│ E-10 記事セル                                 │
│ ┌────────────────────────────┐ ┌──────────┐  │
│ │ E-11 団体名 E-12 ｱｲｺﾝ E-16[更新] │ │          │  │
│ │ E-13 見出し（最大 3 行）      │ │  E-15    │  │
│ │                             │ │ ｻﾑﾈｲﾙ    │  │
│ │                             │ │          │  │
│ │ E-14 公開日時        E-17 ☆ │ └──────────┘  │
│ └────────────────────────────┘                │
└──────────────────────────────────────────────┘
```

- 左にテキスト領域、右に正方形のサムネイル領域（参考イメージ：SmartNews の一覧セル）
- 1 行目：E-11 団体名 → E-12 カテゴリアイコン → E-16 更新バッジ（更新時のみ）の順に横並び。1 行に固定し、折り返さない（収まらないときは §7.5「位置」）
- 2 行目以降：E-13 見出し
- 最終行：左に E-14 公開日時、右端に E-17 スター
- セル間は 1px の区切り線（iOS 標準のリスト区切り）
- E-17 スターを除くセル全体がタップ領域（A-10）

## 5. 状態

部品ごとに分けて書く。「初期表示」は各画面の §5 が定義するため、本書では記事セルの通常状態 ST-01 と状態表示の非表示をもって初期とする。

### 5.1 記事セル E-10

| ID | 状態 | 発生条件 | 表示 |
|---|---|---|---|
| ST-01 | 未読 | 記事をまだ開いていない | E-11・E-13・E-14 は標準の文字色（ラベル色）。E-13 は太字。E-15 は不透明度 100% |
| ST-02 | 既読 | 記事を開いたことがある（A-10 の後）。設定の一括クリア（S-03）で ST-01 に戻る（`Article.updatedAt` があっても ST-03 にはならない。§7.5） | E-11・E-13・E-14 をセカンダリ文字色に変える。E-13 は標準の太さ。E-15 は不透明度 50%。E-12・E-17 は変えない |
| ST-03 | 更新あり | `Article.updatedAt` が存在し、かつその更新の後に記事を開いていない（§7.5）。ただし一括クリア（S-03）より前に検知した更新は対象外 | E-16「更新」バッジを表示。文字色・太字は ST-01 と同じ（更新後は未読として扱う。§8 #19） |
| ST-04 | 保存済み | E-17 で保存した（A-11）。保存を解除すると ST-01 / ST-02 の表示に戻る | E-17 が塗りつぶした星になる。他の要素は変えない。ST-02 と同時に成立する |
| ST-05 | サムネイル無し | `Article.thumbnail` が無い | E-15 の領域に画像の代わりに無地のプレースホルダー（背景より一段濃いグレーの角丸四角）を表示し、セルの高さと見出しの幅は ST-01 と同じに保つ（§8 #18） |
| ST-06 | サムネイル未取得 | `Article.thumbnail` はあるが、画像をまだ取得できていない（読み込み中・オフライン・取得失敗） | ST-05 と同じプレースホルダーを表示。取得できた時点で画像に置き換わる。失敗しても再試行の操作は出さない |

ST-01〜ST-03 は排他（未読 / 既読 / 更新あり）。ST-04〜ST-06 はそれらと同時に成立する。

### 5.2 共通状態表示

「取得済みの記事」とは、配置画面のフィルタ・団体タブ（S-01）や保存の有無（S-02）で絞り込む前の、端末に保持している記事全体を指す。取得済みの記事はあるが絞り込みで表示対象が 0 件になった場合は ST-12（空）であり、ST-10・ST-14・ST-16 にはならない（§8 #24）。

| ID | 状態 | 発生条件 | 表示 |
|---|---|---|---|
| ST-10 | 読み込み中（全面） | 取得済みの記事が 1 件も無い状態で取得を実行中（初回起動の直後がこれにあたる） | E-20 を中央に表示。E-22 / E-24 は出さない |
| ST-11 | 更新中（記事あり） | 取得済みの記事が 1 件以上ある状態で取得を実行中（起動時の裏での取得、Pull to Refresh） | E-21 を一覧の先頭に表示。記事セルはそのまま操作できる（A-10・A-11 は有効）。この間に下部タブを切り替えても取得は続き、戻ったときに成功の結果（記事の追加・更新）が反映されている。失敗した場合は ST-13 / ST-15 のとおり（ST-13 の帯 E-23 は配置画面に戻ったときに表示されている。ST-15 の E-25 は他のタブを表示中に失敗すると出ない）。表示対象が 0 件（ST-12）のときは E-22 の上に E-21 を出す |
| ST-12 | 空 | 表示対象が 0 件。取得済みの記事が 1 件も無い場合は、取得が成功して 0 件だったとき、または配置画面が取得を伴わないとき（S-02）。取得済みの記事がある場合は、フィルタ・団体タブ・保存の有無で 0 件になったとき。取得の実行中・オフライン・エラーの区別は ST-11 / ST-13 / ST-15 の重ね表示で示す。取得済みの記事が 1 件も無い状態での取得中は ST-10 | E-22 を中央に表示。文言は配置画面が指定 |
| ST-13 | オフライン（記事あり） | ネットワーク不通の状態で取得を試みた。取得済みの記事が 1 件以上ある（表示対象が 0 件でもよい） | 記事セルはそのまま表示し、E-23 の帯を一覧の直上に出す。次の取得の結果がオフライン以外（成功、または ST-15）になった時点で帯が消える。ST-15 になった場合は E-23 を消して E-25 を出す（§8 #26）。表示対象が 0 件（ST-12）のときは E-22 の上に E-23 の帯を出す |
| ST-14 | エラー（記事なし） | ネットワークはあるが取得または解析に失敗し、取得済みの記事が 1 件も無い | E-24 を中央に表示（1 行目「記事を取得できませんでした」、2 行目「時間をおいてもう一度お試しください」）。「再試行」ボタン（A-12）で再取得 |
| ST-15 | エラー（記事あり） | ネットワークはあるが取得または解析に失敗し、取得済みの記事が 1 件以上ある（表示対象が 0 件でもよい） | 記事セルはそのまま表示し、E-25 を 3 秒間表示。再試行は配置画面の更新操作（S-01 の Pull to Refresh）で行う。表示対象が 0 件（ST-12）のときは E-22 を表示したまま、E-25 を画面下部（E-01 の直上）に出す。E-25 は配置画面（S-01）を表示中のときだけ出す。失敗の時点で他のタブ（S-02 / S-03）を表示中だった場合は E-25 を出さず、配置画面に戻ったときにも出さない（§8 #25） |
| ST-16 | オフライン（記事なし） | ネットワーク不通の状態で取得を試みた。取得済みの記事が 1 件も無い（初回起動時にオフラインだった場合がこれにあたる） | E-24 を中央に表示（1 行目「オフラインです」、2 行目「インターネットに接続してから再試行してください」、ボタン「再試行」）。「再試行」ボタン（A-12）で再取得。E-23 の帯は出さない |

ST-10・ST-12・ST-14・ST-16 は排他（全面表示は同時に 1 つ）。ST-11・ST-13・ST-15 は記事一覧の表示と重なる。ST-12 は ST-11・ST-13・ST-15 と同時に成立する（例：未読フィルタ ON で全記事既読のままオフラインで更新を試みると、E-22 の空表示の上に E-23 の帯が出る）。ST-11 は ST-13・ST-15 と同時に成立する（オフラインのまま再取得中は E-23 の帯を出したまま E-21 を出す。E-25 の表示中に再取得を始めても E-25 は 3 秒で消える）。ST-13 と ST-15 は排他（直近の取得結果で決まる。「オフラインです」の帯と「更新に失敗しました」が同時に出ることはない）。

## 7. 表示ルール

### 7.1 団体の表示対応（`Article.companyId` → 表示名）

| `takarazuka` | 宝塚 | 宝塚歌劇団 |
| `shiki` | 四季 | 劇団四季 |

- 対応表に無い `companyId` の記事（団体定義の追加が先行した場合）は、E-11 に `companyId` の文字列をそのまま表示する（記事を隠さない）

### 7.2 カテゴリの表示対応（`Article.category` → アイコンとラベル）

要件 §7 の 7 値。アイコンは単色のシンボル（E-11 と同じ高さ）で、モードに応じてセカンダリ色で描画する。ラベルは画面には出さず、VoiceOver の読み上げに使う。

| `cast` | キャスト情報 | キャスト情報 | 人物 2 人 |

### 7.3 日時（E-14）

`Article.publishedAt`（ISO8601）を端末のタイムゾーンに変換して表示する。**時刻は表示しない**（§8 #15）。

| 条件 | 書式 | 例（今日が 2026/9/13 のとき） |
|---|---|---|
| 今日 | 「今日」 | 今日 |
| 昨日 | 「昨日」 | 昨日 |
| 一昨日以前で同じ年 | `M/d` | 9/1、8/28 |
| 前年以前 | `yyyy/M/d` | 2025/12/24 |

- 「今日」「昨日」の判定は端末の日付による（日付が変わった時点で表示も変わる）
- `Article.updatedAt` は E-14 に表示しない（更新は E-16 バッジで示す。§7.5）
- `Article.fetchedAt` は表示しない

### 7.4 既読（F-05）

### 7.5 更新バッジ（F-11）

| 対象 | ルール |

| 文言 | 「更新」の 2 文字。固定 |
