### D-03 追随事項（設計書を reopen するときにまとめて反映）
- §4.4 宝塚: 日付は `.date`（`YYYY.MM.DD`）を主、URL の `YYYYMMDD` を予備（設計は逆）。根拠: 実データで URL スラッグ = 初出日・`.date` = 掲載日で 139 件中 26 件が食い違い、DOM 順は `.date` に一致
- §4.2 宝塚: `TAKARAZUKA_NEWS_URL_RE` は `_(\d+)\.html$`（連番はゼロ埋めされない）、`SELECTORS.link` は項目の親 `<a>`、`tags: ".tag span:not(.label)"`（`.label` は NEW バッジ）、`excludeFromTitle: ".tag, .date"`、`excludeFromImage: ".tag, .txt"`（`icon_blank.png` 外部リンクアイコンを除外）。一覧にサムネイル画像は無い
- §4.6 宝塚: `tagMap` は `配信・放送 → streaming` の 1 件（設計初期値 9 件は実タグと不一致）。§4.6 末尾「無料配信 → streaming」は団体表 `ticket: ["友の会"]` と競合し `ticket` になる（**開発者判断: 「友の会 + 配信」を `ticket` とするのが期待どおりか**。§9 へ）
- §5.4: リンクは項目の親 `<a>`。一覧ページ自身を指す href（`origin + pathname` 比較、`index.html`・末尾スラッシュ同一視）は `no_link`
- §6: `no_link` の定義に「一覧ページ自身を指す href」を含める。宝塚行に `warn("date fallback to url", { sourceId, count })`（0 件なら出さない）を追加
- §7.3 宝塚行: 「無料配信」→「9月配信のお知らせ」、`NNN` 表記、破棄ケースの差し替え列、「日付の予備経路」4 ケース＋`count=2`、「一覧ページ自身を指す href」4 パターン。「記事単位の破棄」は実 DOM と同構造の合成 HTML を許容
- §8 #1: サイト非依存部分（`SourceDeps`・`classify`・`toHttpUrl`・`pointsToListPage`・`resolveHref`・`ParsedYmd`/`toDateOnlyResult`/`ymdFromMatch`・`extractThumbnail`・`extractTitle`・破棄集計）は約 120 行で、見積り（2 型・3 正規表現・6 行）を大きく超える。§8.1 の D-01 将来改訂候補に `domain/url.ts` の `toHttpUrl`・`isSameListPage`、`domain/datetime.ts` の `ymdFromMatch`、`DiscardCounter` を追記
