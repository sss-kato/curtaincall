### 第 1 段階で撤回した 2 件（記録）

- **`notifyUpdates` の追加**：第 2 周で「drift の自動 updates 追跡は cascade 先のテーブルを検知できない」という前提で追加したが、**誤り**。生成コード `app_database.g.dart` の `streamUpdateRules` に `articles` の delete → `read_states` / `saved_articles` の delete を伝播する `WritePropagation` が `onDelete: KeyAction.cascade` から自動生成されている。トランザクション内では no-op のデッドコード、トランザクション外では二重発火になっていた。現在は「なぜ不要か」をコメントで残している
- **`test/helpers/seed_articles_test.dart`**：ヘルパの自己検証テスト。CLAUDE.md のテスト方針の例外（パーサーのフィクスチャ／外部境界 infra／設計書 §7 の純粋関数）のいずれにも該当せず、D-05 §7 にも無いため削除した

- `copyWith` の doc が「理由」と「出典（D-05 §4.1）」を一体で書いており、§4.1 には署名しか書かれていない
