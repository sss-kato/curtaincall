### 検証の要点

**D-05 §7 の欠落ケースは、実装エージェントの「§7 には 5 件しかない」という報告と食い違ったため、司令塔が §7 を直接読んで確認した。** 実際には 6 件あり、6 件目は「`watchNotificationSettings()` を購読 → settings への書き込み（`feed_etag` の upsert）では再発火しない」。これは `.distinct(MapEquality)` の効果を担保するケースで、**欠けていても他の 5 件は緑のまま**だった。spec-reviewer の指摘が正しかった。

第 2 段階では、`setNotificationEnabled が例外を投げる → syncSubscriptions は 0 回、例外が伝播する。設定は変わらない` と `行無し → true を返し settings.unread_filter = '1'。watchUnreadFilter() が true を流す` の 2 ケースについて、**テストの `it` 名が D-05 §7 の行と 1 文字ずつ完全一致すること**を機械照合で確認した（隣接文字列連結の改行位置を原文の空白位置へ寄せ、`missing_whitespace_between_adjacent_strings` lint も同時に満たす形にした）。
