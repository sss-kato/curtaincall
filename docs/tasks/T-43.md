## 内容

D-04 §10 の **T-P**。本改訂で**振る舞いが変わらない**片付けだけを集めたタスク。振る舞いが変わる分は T-39（T-F3）と T-40（T-F4）が引き取り済み。

`/pm plan` の際に D-04 §10 から写像し損ねており、T-01〜T-42 のどれにも割り当てられていなかった（T-40 のレビューで「`PushSubscriptionCoordinator.isRunning` は T-P が非公開化する対象」と指摘された時点で欠落が判明）。

### 注記の削除

1. `features/articles/infrastructure/http_articles_feed.dart` の `TODO(T-21)`（§4.3 に TLS 系 `IOException` の分類行が入ったため）
2. `core/database/app_database.dart` の `TODO(T-20)`（§4.2 に `settings` の共通アクセサが入ったため）
3. `features/articles/domain/article.dart` と `pubspec.yaml` の `TODO(T-18)`（§4.1 に `@immutable` の方針、§4.8 に `meta` の依存が入ったため）

### 実装済みコードの移動

4. `tabControllerProvider` を `lib/app/root_tabs.dart` から `lib/app/tab_controller.dart` へ切り出す（§5.8・§8 #46。`root_tabs.dart` は読む側に回る。D-05 側の import も追随）
5. `SettingKeys.feedEtag` / `feedGeneratedAt` / `feedUnsupportedSchema` を **`features/articles/infrastructure/feed_state_keys.dart`** の `FeedStateKeys` へ移し（`domain` ではなく `infrastructure`。§8 #47）、`drift_article_repository.dart` の `settings/domain` import を外す（§4.4）
6. 復帰時の再同期の判定を `AppLifecycleSync._resyncSubscriptionsIfFailed` から `PushSubscriptionCoordinator.resyncIfNeeded()` へ移し、`lastResult`・`lastRunFailed`・`pending`（と `PushSubscriptionCoordinator` の `isRunning`）を**非公開にする**。§7 の `group('pending')` を `group('復帰時の再同期')` に差し替える（§5.3・§5.6・§8 #52・#53）

**`SyncCoordinator` の `isRunning` は `@visibleForTesting` を付けて残す**（§8 #53。非対称であること自体が決定事項）。

### T-39 で実施済みのため本タスクの対象外

- D-04 §10 T-P の **(6)**「`articleCountErrorLog` Provider を廃し、記録を `AppLifecycleSync.initState` の `ref.listenManual` へ移す」は **T-39 で実施済み**。T-F3 が §5.4.2 の `feedStatus` を丸ごと書き直す際に、この Provider の唯一の起動点（`ref.watch`）が消えるため、残すと件数購読の障害が 1 行も記録されない状態になることから、spec-reviewer の判定により T-39 に含めた
- D-04 §10 T-P の **(7)**（`ListStatus`・`FullView` の切り出しと `syncsOnLaunch` の廃止）は設計書の時点で T-F3 に移管済み。**T-39 で実施済み**
