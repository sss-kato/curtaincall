## 内容

D-02（approved、2026-09-25）§8.1 の実装追随 **(a)・(e)・(c) の storage 分・(f) の §7.3 分**。設計書が正で、実装が追いついていない箇所を直す。

**最優先は (a)。** 現行の `maskCredentials` は URL 形式（`/(https?:\/\/)[^/\s]+@/gi`）しか見ておらず、**実運用で実際に現れる形（`actions/checkout` が `.git/config` の `http.https://github.com/.extraheader` に入れる `AUTHORIZATION: basic <base64>`）をマスクしない**。git の stderr がそのまま Actions のログに出ると GitHub トークンが残る（要件 §5「秘密情報」、D-02 §4.10・§8 #40）。

- **(a)** `maskCredentials` を §4.10 のマスク規則表どおりにする。extraheader 形式は「`basic` / `bearer` の直後の**空白の連続**（1 つ以上。半角スペース・タブを含む）の後から、次の空白または行末まで」を伏せ字にする。URL 形式のマスクは維持する
- **(e)** `PUBLISH_BRANCH` を `paths.ts` から `git-articles-publisher.ts` の**非公開定数**へ移す（§4.10・§8 #49。`paths.ts` はパス定数のみを持つ）
- **(c)** 実装側の `// D-02 追随: …に無い` コメントのうち、本改訂で規定が入った次の 4 か所を削除するか通常の参照コメントに置き換える：`git-articles-publisher.ts:18`（`GIT_TIMEOUT_MS`）・`sanitize-git-output.ts:1`・`paths.ts:2`・`articles-file-store.ts:38`（ENOENT を info に落とす）
- **(f)** §7.3 に追加された 4 ケースのテストを書く：`execFile` の第 3 引数の固定・`git commit` 失敗・extraheader の後続文字列・**extraheader のタブ + 半角スペース 2 文字**
