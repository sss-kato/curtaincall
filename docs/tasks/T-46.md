## 内容

D-02（approved、2026-09-25）§8.1 の実装追随 **(b)・(c) の残り・(f) の §7.1 分**。本タスク群で最も大きい。

現行の `RunSummary` は `published: boolean` のままで、D-02 が定めた `publishOutcome`（4 値）/ `publisher` / `survivingChanges` を持たない。そのため **2 つの「静かな停止」の検知が動いていない。**

**とくに `survivingChanges` は急ぐ。** D-02 §8 #51 のとおり、第 2 周まで採っていた `dropped === 0 && created + updated > 0` という条件は、団体の記事が 100 件（上限）に達すると新着 1 件につき末尾 1 件が必ず落ちるため**定常運用では一度も真にならない**。**本番の `data/articles.json` は既に宝塚が 100 件に達しており、この状態に入っている。**

実装するもの（D-02 の該当節が正）。

- `DetectDiffResult.stats.survivingChanges`（§4.6）と `§5.2 手順 7b` の算出（手順 7 と**同じ走査**で、新着**または更新**かつ切り詰め後に残っているものを数える。手順 8 の置き換えの影響を受けない）
- `RunSummary` を判別可能ユニオンに（§4.8）。`publishOutcome: "published" | "no_changes" | "skipped" | "unknown"`・`publisher: "git" | "noop"`・`survivingChanges`
- `buildFailureSummary(params)` を **4 引数**（`clock` / `error` / `publisherKind` / `notificationGatewayKind`）にし、`sourceFailures` の導出（`error instanceof SnapshotMissingError`）を**関数の中**へ寄せる（§8 #46。`main.ts` に `instanceof` を書かせない）。`ArticlesValidationError` も `"skipped"`（§8 #47）
- `sanitizeFailureMessage` / `MAX_FAILURE_MESSAGE_LENGTH` の `export` を外して非公開に（§8 #54）。切り詰めは**コードポイント単位**（§8 #55）
- `RunCollectionInput.dryRun` を追加し、手順 8 の判定をそこへ移す（§8 #45）。`publisherKind` / `notificationGatewayKind` はサマリ記録専用
- `main.ts` 手順 4b で `GITHUB_ACTIONS === "true" && CURTAINCALL_DRY_RUN === "1"` を**起動時に拒否**（終了コード 1。§8 #44）
- `main.ts` 手順 10 の carve-out：**手順 3〜6 の失敗では `buildFailureSummary` を呼ばずサマリを書かない**（§5.5）
- `RunCollection` 手順 7 の矛盾判定を `diff.stats.survivingChanges > 0` に、手順 5 のログを `{ failures: collect.failures.length }` に（§4.7 の `LogFields` はスカラーのみ）
- `.github/workflows/collect.yml` を §5.6 に同期（jq 5 か所の型ガードとフォールバック、本文サマリの `残存 \(.survivingChanges)`、`discardedByCompany` の `(.value | type) == "number"`、2 つの検知ステップ、`outputs`）
- **(c)**：`run-summary-store.ts:7` と `run-collection.ts:95` の `// D-02 追随` コメントを削除または通常の参照コメントに置き換える

> **重要（D-02 §8.1 (b) の制約）**：`RunSummary` の型変更（§4.8）と `collect.yml` の jq の書き換え（§5.6）は**必ず同一コミット**で入れる。片方だけ先に入ると `published` の判定が噛み合わず、Pages が更新されない、または毎時無駄にデプロイされる。
