## 内容

D-02 §10 **Task F（collect-articles と detect-diff）の残項目**。「状態」セルは「実装済み。残作業あり：§8.1 (v)（`warn("invalid raw article")` のフィールドを 3 つにする）、(f) のうち §7.1 の `collect-articles` 行に追加したケース、(h) のうち `application/collect-articles.ts` のコメント削除」。

着手時の実測では、(h) の `application/collect-articles.ts` の自己申告コメントは T-47 で既に削除されている。残っていないものは「削除済み」として扱い、新たに書き足さない。
