## 内容

D-02 §10 **Task G（storage と publish-articles）の残項目**。「状態」セルは「実装済み（T-07 とホットフィックス `fix/publish-staged-diff`）。残作業あり：§8.1 (ii)（§7.3 の `maskCredentials` 9 ケースと `GitArticlesPublisher` の「対象とブランチの固定」）・(iv)（`AUTH_SCHEMES` の定数化と 3 ケース）・(f) の §7.3 4 ケース・(c) のうち `git-articles-publisher.ts` / `sanitize-git-output.ts` / `paths.ts` / `articles-file-store.ts` / `run-summary-store.ts` のコメント削除」。本タスクは指示のとおり `git-articles-publisher.ts` のコメント削除を (c) の担当範囲とする。

主題は 2 つ。(1) `sanitize-git-output.ts` のマスク対象スキームを `AUTH_SCHEMES = ["basic", "bearer", "token"] as const` として定数化する（§8 #62 で確定）。(2) §7.3 に積み上がった回帰ケース（`maskCredentials` の 9 + 3 + 4 ケースと `GitArticlesPublisher` の「対象とブランチの固定」）を書く。**`SEP` と tempered greedy token の形（各文字位置での否定先読み）は一字も変えない**。崩すと §8 #59 が塞いだ素通り（T-44 で 5 回再発した欠陥）が再発する。

着手時の実測（2026-10-17）では `AUTH_SCHEMES` は未定義で、`sanitize-git-output.ts:73` に D-02 追随コメントが残っている。(c) が挙げる `git-articles-publisher.ts` のコメントは T-44 で既に削除済みなので、残っていないものは「削除済み」として扱い、新たに書き足さない。
