## 内容

D-05 §10 **T-T E-18（バージョン行）の折り返し**（§8 #53。S-03 §8 #20・§7.5 の反映。実装済みの `settings_screen.dart` への追随）を実装する。

- **新規なし。改修 1**：`lib/features/settings/presentation/settings_screen.dart`
- E-18 は `CupertinoListTile.additionalInfo` を使わず、ラベルと値の組み立てを `title` に渡す private ヘルパ **`_versionTitle`** に移す：`LayoutBuilder` + `TextPainter.computeWidth` で「ラベル + 間隔 + 値」が 1 行に収まるかを実測し、収まるなら `Row`（ラベルは非 flex で左、値は `Expanded` の右寄せ）、収まらないなら `Column`（ラベル左寄せ・値右寄せの 2 行）にする。値が `null`（未着・失敗・**空文字**）ならラベルだけ（§5.9・§8 #53）
- `_wrappableText` は `style` / `textAlign` の 2 引数を受け取る形に拡張するが、`maxLines`・`overflow` は渡さない（素の `DefaultTextStyle` コンストラクタのまま。§5.9・§8 #51・#53）
- 設計書側の依存：T-O（= 実タスク T-35）完了済み（本書の反映後に本タスクだけを切る）、**D-04 §10 T-F5a（= 実タスク T-53）**
- **T-53 と同じ `settings_screen.dart` を改修する。`_logWarn` の位置引数化は T-53 の範囲で、本タスクでは触らない**（D-05 §10 T-T の依存欄・§5.9、D-04 §8.1 の D-05 宛・§4.9）。順序は T-53 → 本タスク
- **触るファイルが他タスクと重ならないため T-33（T-M）・T-34（T-N）・T-55（T-S）と並行可**（重なるのは先行する T-53 だけ）
